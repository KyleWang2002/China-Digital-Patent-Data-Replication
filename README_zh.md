# 中国数字技术专利：数据采集与空间匹配

[English README](README.md) · [方法说明](docs/METHODS.md)

项目源于我对陈晓红等（2024）发表于《经济研究》的论文《数字赋能、技术创新与空气污染治理——来自专利文本挖掘的证据》的复现尝试，重点是其中的**数字技术专利数据构建**。我曾使用 Selenium 操作 IncoPat 动态网页，提取专利申请信息，并进一步整理了文本筛选、地理编码和空间匹配的代码。

## 项目内容

- **专利采集：** 通过动态详情页读取申请号、申请日期、申请人等字段，保留了部分[实际采集记录](examples/incopat_ui_excerpt.csv)。
- **文本处理：** 字段清洗、专利去重，以及人工智能、大数据、云计算、区块链和5G五类数字技术的初步关键词筛选。
- **地理匹配：** 可选的申请人地址地理编码、坐标转换和专利—空气监测站点距离计算；以5 km为基本半径，也支持其他距离。
- **指标构建：** 计算监测站点周边随时间累积的专利数量；有专利价值度数据时可计算价值度存量。

原论文使用**1985—2021年约41万条数字技术专利**与**2,016个空气质量监测站点**。这里保存的是我早期的少量网页实验记录，以及用于演示完整处理流程的虚构数据，不等同于原论文样本。本仓库主要展示专利数据处理，不涉及完整复现论文的回归结果。

## 处理流程

```text
IncoPat详情页 / 合法导出数据
          ↓
专利解析与去重
          ↓
五类数字技术关键词筛选
          ↓
地址地理编码与坐标统一
          ↓
专利—空气监测站点空间匹配
          ↓
站点—日期层面的累计专利指标
```

## 运行

使用 Python 3.10+，在仓库根目录执行：

```bash
python -m pip install -e .
python scripts/run_demo.py
python -m unittest discover -s tests -v
```

离线示例会在 `outputs/demo/` 生成结果，不需要数据库账户或API密钥。处理自有专利导出数据的命令见[方法说明](docs/METHODS.md)。IncoPat 浏览器采集需要有权限的账户并手动登录，页面选择器也可能随网站更新而变化。
